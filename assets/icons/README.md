# Icon sources

Cryptocurrency and network logos are sourced as branded SVGs from the
[`@web3icons/core` 4.0.56 package](https://github.com/0xa3k5/web3icons/tree/main/packages/core),
which provides curated token and network assets. The package is MIT licensed;
see [LICENSE-Web3Icons](LICENSE-Web3Icons).

The TON currency icon uses the collection's TON network logo. The Dogecoin
network icon uses its matching DOGE logo because the collection does not ship a
separate Dogecoin network asset.

The Lightning Network icon is by `@tlindi` and comes from the
[Bitcoin-and-Lightning-Network-logos-and-icons project](https://github.com/bitcoin-yhdistys/Bitcoin-and-Lightning-Network-logos-and-icons),
under CC BY-SA 4.0. Its source SVG is kept at
[`networks/lightning.svg`](networks/lightning.svg); see
[LICENSE-Lightning-Icons](LICENSE-Lightning-Icons).
